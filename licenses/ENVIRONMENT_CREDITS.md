# Ground operation assets

Rainforest models and textures from Poly Haven, CC0:

- [Island Tree 01](https://polyhaven.com/a/island_tree_01), adapted with reduced geometry and Godot-generated mesh LODs.
- [Fern 02](https://polyhaven.com/a/fern_02), one botanical specimen extracted for spatial instancing.
- [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01), one rock extracted for spatial instancing.
- [Forrest Ground 01](https://polyhaven.com/a/forrest_ground_01), albedo, normal and roughness maps.

[Poly Haven asset license](https://polyhaven.com/license): CC0, permits game use and redistribution. Download checksums were verified against the public API manifests. Source assets remain in `environment_sources/polyhaven` outside the exported game. `prepare_mode_assets.py` documents conversion.

The indoor facility layout, field knife model, knife icon and scenario code are original project work. Existing industrial surface and weapon credits remain in WEAPON_CREDITS.md and the project README.

## Original facility assets

Workstations, monitors, keyboards, equipment cabinets, server racks, ergonomic chairs, display artwork, ceramic floor texture and interior architectural geometry were authored for this project. Source generators: `build_facility_props.py` and `facility_textures.py` in the workspace root.
